## 1. 产品定义

- **一句话**：面向 Windows x64 原生软件的**代码保护 + 授权签发套件**——VM 代码保护、
  反调试、完整性、RSA 离线签发与分级授权一体，源码可见、无第三方运行时依赖。
- **对标**：Themida / VMProtect / CodeMeter 的**轻量自研替代**。差异化：不是黑盒
  混淆器，而是"复合门槛 + 每构建随机化 + 防伪造签名 + 断源装载"的可审计组合。
- **形态建议**（决策点 D1）：库 + 命令行工具链（当前形态）→ 可选做图形化保护器。
- **目标客户**：独立开发者、小规模商业软件、企业内部分发、代码审计培训。
- **价值主张**：
  1. 把单镜像破解成本抬到小时~天级，并让"生成合法授权"在信息论上不可行（RSA 离线私钥）；
  2. 每次构建互异，防批量 patch / 防通用还原器；
  3. 分发时 exe 与 vm.blob 分离，静态只拿 exe 无从分析（断源）。

## 5. 风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| 私钥泄露 | 防伪造锚点崩塌 | 分级管理 + 离线存储 + 轮换流程（OPS §3） |
| 兼容性误报（反调试误杀） | 客户流失 | 真机矩阵（COMPAT）+ 咨询项只报告策略 + 可配置策略 |
| 破解/逆向进展 | 收入侵蚀 | 持续随机化 + 每客户独立构建 + blob 绑定升级（OPS I1 扩展） |
| 法律/合规 | 分发受限 | EULA + 区域合规咨询（OPS §7） |
| 单点（个人开发） | 进度风险 | 文档完备保证可交接（HANDOVER） |
