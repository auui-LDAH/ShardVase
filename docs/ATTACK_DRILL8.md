### 3.2 **函数级证据（决定性）**


### 4.1 诚实边界（**不可过度声称**）

```
① 随机化是**分发级**而非"每次运行"级 —— 同一份发布内偏移**稳定**，
   攻击者对**同一发布**仍可标定一次、反复使用
   => 它防的是"**跨发布复用成果**"，不是"单次破解"
② 未验证: 攻击者若**自动化**（脚本化定位 + patch），成本是"每次发布跑一次脚本"
   而非"人月级重做" —— **自动化程度决定真实阻力**
   => 建议 DRILL9 专门测"自动化 patch 流水线的成本"
③ 本 drill **未实跑**真实 patch（DRILL7 已证手法），只测**定位是否失效**
   -> 属"**部分实证**"（定位维度 ✅ / 端到端 patch 未复跑）
```
