## 1. 背景与目标

### 1.1 前两轮成果
- 第一轮：23 项全结论（15 BLOCKED / 0 BREACHED / 8 PARTIAL）；
- 第二轮：13 项全结论（4 BLOCKED / 9 PARTIAL / 0 SKIP）+ 2 个防御修复：
  - **G2 补洞**：运行期 IAT 校验（watchdog 快照比对，改写 1.9s 识破）；
  - **N2 EXIT 策略**：`--dbiguard-policy EXIT`（hook 检测即 0xDB）。

### 1.2 第三轮动机
前两轮**单项攻击**证明防御各自有效。但真实攻击者会**组合手法**：
静态定位 → 绕过检测 → patch → 伪造 → dump。第三轮验证：
1. **组合攻击链能否逐层推进**（每步被哪层防）——揭示"防御纵深"的真实
   薄弱环节；
2. **新修复回归**：IAT 校验/EXIT 策略是否被**绕过**（如先清 watchdog 再 hook）；
3. **对已修复边界的对抗升级**：G2 修复后攻击者会尝试**绕过 IAT 校验**
   （如改写快照本身/暂停 watchdog 线程）。

### 1.3 目标
1. 设计 **5 条组合攻击链**（真实攻击者完整流程）；
2. 每条链验证**各防御层拦截点**（哪层拦/哪层破）；
3. **回归 4 项**：G2 IAT 校验可被绕过？EXIT 策略可被绕过？新修复误杀率？
4. 输出第三轮报告（组合链拦截矩阵 + 修复回归结论）。

## 2. 组合攻击链设计（5 条）

### C1: 注入 → hook → patch 全链
```
① 定位 static (dumpbin/字符串) ② DLL 注入 (user32) ③ IAT hook ④ patch result
```
- **预期拦截点**：① N4/N1（无直接 call/密文）② 无静态拦截（注入可行——
  记录）③ **G2 新 IAT 校验** ④ N3/看门狗。
- **验收**：链在第③步被拦（G2 生效）；若 ③④ 都过=整体破防。

### C2: 伪造 → 替换 → 回滚全链
```
① 伪造 blob v0 ② 替换 vm.blob ③ 回滚旧版
```
- **预期**：①②③ 全被 blob 签名拦（第一轮 F2/F3/F5 已单项验证；组合验证
  的是"换 blob 绕过完整性"）。
- **验收**：链在第一步即拦。

### C3: 清检测 → patch → 驻留绕过
```
① 清 PEB ② 暂停 watchdog 线程 ③ patch .text? (文件级) ④ 内存 patch result
```
- **预期**：① 多因子仍工作；② NtSuspendProcess 暂停 watchdog 线程 →
  窗口内 patch 内存 → 恢复；**验证 watchdog 暂停是否可被利用**（G3 已显示
  内存 patch 非文件 CRC 范围——但**暂停 watchdog 后文件级 patch 也能做**？
  .text patch 会被当前 check 杀，除非暂停）。
- **验收**：若暂停 watchdog + patch .text 成功运行 = **防御纵深缺口**（记 BREACHED）。

### C4: dump → 还原引擎 → 构造合法输入
```
① D2a 运行期 dump (已知明文) ② 还原 VM 引擎语义 ③ 构造通过校验的输入
```
- **预期**：① 已知边界（明文）② 需完整还原（成本高，时间受限标记
  PARTIAL）③ **私钥离线锚点**（license 无法伪造）→ 最后仍需合法签名。
- **验收**：链路终点被 RSA 锚点拦（BREACHED 不可能，除非私钥泄漏）。

### C5: 在线对抗 + 组合
```
① 中间人替换 blob ② 伪造会话期望值 ③ 离线固定 patch
```
- **预期**：① blob 签名拦；② N5 在线值覆盖（T25/T26）；③ 离线可 patch
  （已知边界）。
- **验收**：①②被拦，③记录边界。

## 3. 防御回归（4 项）

### R1: G2 可绕过性
- **手法**：改写 IAT **前**先暂停 watchdog 线程（NtSuspendThread 主线程）
  → 改 IAT → 恢复 → 快照比对仍识别？
- **预期**：快照在 watchdog 启动时已建立——暂停后改写 → 恢复后首个
  周期 detect。验证"快照提前建立"设计有效。

### R2: EXIT 策略可绕过性
- **手法**：注入前清 dbiguard 检测标志？——检测在启动早期（hook 扫描）
  绕不过；尝试注入后在检测后 hook → 不触发（已测，单次流程）。
- **验证**：FAQ——EXIT 策略的检测窗口（启动时）vs 驻留（watchdog 周期
  antidebug，但 dbiguard 是否周期重扫？——**dbiguard 只在启动扫一次**，
  驻留 hook 注入不被周期检测 → **缺口**）。

### R3: 新修复误杀率
- **手法**：干净环境跑 `--loop-vm 200` 长驻留，确认 IAT 校验/EXIT 策略
  零误杀（watchdog 周期复查不误报）。
- **预期**：0 误杀（对照此前 T6/T11）。

### R4: 防御纵深薄弱点盘点
- 汇总 C1-C5 各链的**实际拦截点**和**穿透点**，更新 THREATMODEL。
