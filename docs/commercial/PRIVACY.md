# 隐私与数据处理说明（初稿）

> **声明**：初稿模板，不构成法律意见；上线前按销售地区（如个保法/
> GDPR）审定。

## 1. 一句话
**我们的套件默认零遥测、零使用统计、零网络调用** —— 保护运行时与
授权验证完全在本地完成，这是产品设计，不是可选项。

## 2. 我方运行时（嵌入客户产品的保护壳）
| 数据 | 采集？ | 说明 |
|------|--------|------|
| 机器标识（卷序列号/机器 GUID/磁盘物理序列号）| 仅本地计算 | 仅用于本机授权校验，**不上传** |
| 序列号/license 内容 | 仅本地验证 | 本地 RSA 验签与非对称签名，明文不外发 |
| 使用行为/统计 | **否** | 无遥测上报 |
| 网络连接 | **默认无** | 仅当**客户自行**启用在线模块（check-url/blob-url 指向其自己的端点）时才会连接 |

## 3. 我方运营（签发方）
仅保留为履行服务所必需的数据：
- 订单/发票信息；
- 支持工单内容；
- 签发台账（机器标识、序列号、签发时间——存于我方服务器/你方服务器，
  哈希链保护防篡改）；
- 不收集、不出售、不分享此类数据给第三方（法定要求除外）。

## 4. 客户数据的归属
被授权方产品所处理的**其终端用户数据**与我方无关；终端用户的隐私
责任由其服务条款单独界定。

## 5. Cookie / 广告 / 追踪
网页/文档站如有 Cookie 仅用于会话必需；无广告跟踪。

## 6. 保存期限与删除
- 台账：按运营需要保留（至少）至协议终止后 6 个月；
- 支持沟通：删除请求通过支持渠道提交，15 个工作日内处理。

## 7. 合规提示
本说明为模板；正式上线前应根据适用的法律（《个人信息保护法》、
GDPR 等）与销售地区完成合规审定。
