## 1. 本次阶段完成内容（2026-08-30）

### 1.1 攻击侧工具链（新领域：加固 ↔ 破解双向打通）

规划：`docs/MEMPATCH_PLAN.md`（D1-D4 决策已确认）
实证：`docs/ATTACK_DRILL7.md`

**A. WinPE-SymPatcher**（`tools/attacker/winpe_sympatcher/`）— **实证完成**
- PE/MAP 符号解析器（MAP + 导出表 + COFF 符号表三通道）；
- 附加 + 写内存（OpenProcess/WriteProcessMemory + ASLR 换算）；
- **端到端实证**：patch `prot_antidebug_detected` 函数头（`xor eax,eax; ret`）
  → **"盾"的判定被永久关闭**（DETECTED → clean 持续）；
- 关键结论：
  - 写判定布尔**无效**（周期重算覆盖，与 DRILL2 P4-2 一致）；
  - **patch 判定函数本体有效**（真实破解者工具链能力）；
  - RELEASE 构建无 COFF 符号 → 需 MAP/PDB（记录为边界）。

**B. Android-JniPtracePatcher**（`tools/attacker/android_jniptrace/`）— **宿主编译就绪**
- ELF64 .symtab/.dynsym 符号解析器（**6/6 符号命中**，JNI 导出定位正确）；
- JNI 补丁模块（同进程免 root / ptrace 附加 root 双模式）+ 命令行版；
- 修复记录：ELF64 节头结构体 `sh_size/sh_addralign/sh_entsize` 必须 8 字节对齐；
- 待真机验证（NDK/root 环境，EXTENSION_PLAN T1 第一项）。

### 1.2 Release 构建 bug 修复（重要）

- **问题**：Release 构建反调试误报（0xDB 自杀，351ms）；
- **根因**：selfcrypt 加密了 `prot_antidebug_scan`，而 `prot_antidebug_apply_policy`
  在解密窗口外调用它 → 执行密文 → 误报；
- **修复**：`demo/main.c` 将 apply_policy 调用包入 `sc_ext_enter/leave` 解密窗口；
- 修复后 Release 完整跑通（反调试通过 → 校验通过 → 欢迎语，看门狗 30s+）。
