# 杀软误报申诉流程（4 家 + 微软）

> 状态：渠道清单（2026-08-28 调研）；样本实测后再提交。
> 原则：只申诉**合法软件**的误报；材料齐备（说明+指纹+签名+官网/版权页）
> 可显著加快审核。

## 通用材料包（每家提交都用）
- 软件说明：ShardVase 是什么、保护原理一句话、官网仓库 URL、联系方式；
- 文件指纹：SHA-256（`Get-FileHash`）；
- 签名：代码签名证书指纹（目前自签 pfx → 无信任根的证书价值有限，
  但附上报毒名对应的样本依然有用）；
- 复现说明：杀软版本 + 报毒名 + 触发动作（扫描/执行）；
- 声明：软件不含恶意行为，同意签署误报声明。

## 提交模板（邮件/表单正文）
```
产品: ShardVase（Windows x64 软件保护与授权套件）
官网: https://github.com/auui-LDAH
描述: 自研反逆向保护（VM 混淆/自加密/完整性校验），无网络遥测。
      自修改与解密执行行为可能导致行为引擎误报。
文件: <样本名> SHA-256: <hash>
报毒名: <如 Heur.Suspicious...>
复现: <扫描/执行/安装后触发>
申明: 本文件为合法软件样本，如有恶意行为愿承担相应责任。
联系方式: <邮箱>
```

## 预期效果（诚实）
- Defender：有签名或通过 WDSI 申诉，一般 2 周内调整；
- 自签 pfx 无信任根：申诉仍有效但慢；
- 真正的"根治"仍是正式代码签名证书（等有现金流采购）——申诉与签名
  是互补关系，不是替代。
