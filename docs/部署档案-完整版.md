## 7. 应用配置要点

### 7.1 主站（volga）
- Spring Boot 4.x（JAVA_TOOL_OPTIONS: MaxRAMPercentage=70）
- 数据库：jdbc:mysql://mysql:3306/volga（容器内服务名）
- 会话：SESSION_COOKIE_SECURE=true（仅 HTTPS）
- Flyway 禁用（ddl-auto=update，生产 schema 由 Hibernate 推导）
- WebSocket：/ws/chat、/ws/notifications（需认证）
- 文件上传：10MB/单文件，200MB 请求体（nginx）
- 邮件：SMTP smtp.qq.com:587（SPRING_MAIL_* 在 .env）

### 7.2 Halo 博客（volga-halo）
- 数据源：r2dbc:mysql://volga-mysql:3306/halo（应用配置挂载）
- external-url: https://blog.qvorqio.cn
- 数据存储：extensions 表（Halo 自定义 blob 格式）
  - **重要：blob 是二进制安全格式（`\\"` 双反斜杠），禁止用 Python 读改写！**
  - 正确改数据方式：MySQL 原生 REPLACE（字节级）或 UI/API
- 附件：/root/.halo2/attachments（halo-work volume）
- 主题：theme-earth（Fragment Nexus 定制）
  - 主题文件：/root/.halo2/themes/theme-earth/templates/（layout/footer/index 已定制）
  - 主题配置：/registry/configmaps/theme-earth-configMap（DB 中）

### 7.3 nginx（volga-nginx）
- 配置挂载：/opt/volga/volga-server/nginx/nginx.conf → /etc/nginx/conf.d/default.conf
- 安全头：HSTS/nosniff/X-Frame/CSP/Referrer/Permissions
- 限流：api 10r/s、login 10r/s、upload 2r/s（主站）；blog_login 5r/s、blog_api 10r/s（博客）
- 静态缓存：hash 文件 365d、Halo 静态 7d
- 上传限速：10MB/s

## 9. 备份与恢复

### 9.1 每日备份（backup.sh，cron 02:30）
```
/opt/volga/backups/volga-backup-YYYYMMDD-HHMMSS/
├── mysql-volga.sql      # 主站库 mysqldump
├── halo-mysql.sql       # 博客库 mysqldump
├── uploads.tar.gz       # 主站上传 volume（~1.1G）
├── data/                # 应用数据目录
├── config/              # 配置文件快照
└── manifest.json        # 清单
```
- 自动清理 7 天前备份

### 9.2 恢复
```bash
# 主站库
docker exec -i volga-mysql mysql -uvolga -p<密码> volga < mysql-volga.sql
# 博客库
docker exec -i volga-mysql mysql --binary-mode -uhalo -p<密码> halo < halo-mysql.sql
# 上传卷
docker run --rm -v volga-server_app-data:/data -v $(pwd):/backup alpine tar xzf /backup/uploads.tar.gz -C /data
```

### 9.3 重要注意事项
- **Halo blob 格式**：extensions 表数据是二进制格式，恢复用 `--binary-mode` 原样导入
- **改密码**：必须用 Java Argon2PasswordEncoder（Halo 容器内 spring-security-crypto jar）生成哈希，MySQL 字节级替换，禁止 Python 读改写

## 13. 已知坑与经验

1. **Halo blob 二进制格式**：extensions 表数据不能 Python 读改写（会破坏 `\\"` 转义），必须 MySQL 字节级操作或 UI/API
2. **ConfigMap 必须有 creationTimestamp**：缺失导致 Halo 启动崩溃（schemeInitializer NPE）
3. **PowerShell 转义**：远程 ssh 命令里 `$()`、`\"` 会被本地展开，复杂命令写脚本文件 scp 后执行
4. **本地网络不稳**：GitHub push 直连间歇失败，需重试或代理 7890
5. **Halo 注册开关**：configmaps/system 的 user 段 allowRegistration（已关）
6. **nginx reload**：配置挂载 ro，改挂载源文件后需 docker restart volga-nginx（reload 可能不读新配置）
7. **主站与博客独立**：域名/证书/nginx server block 各自独立，互不影响
