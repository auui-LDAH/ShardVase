# 给软件加一道"不可复制"的锁：反逆向保护与离线授权实录

> 一篇关于"怎么把软件的授权和代码保护做扎实"的工程记录。
> 内容全部来自真实构建与实测，不含宣传话术。

---

## 一、为什么做这件事

卖软件的开发者几乎都会遇到三件事：软件被逆向破解、一份授权被到处拷贝、
试用/分级授权靠手工 Excel 管理。市面上的方案要么贵（VMProtect 类）、要么
把授权数据放在第三方手里（在线授权服务）、要么"壳"很猛但被 dll dump 就
破功。

我们的目标：**一套自研、可实证、完全离线可控的 Windows x64 保护与授权
体系**——从代码保护到签发台账，全部自己掌控。

## 二、做了什么（技术主线）

### 1. 代码保护（让它难被逆向）
- **自定义 VM 混淆引擎**：关键逻辑翻译成私有字节码运行（不是套壳），
  构建期操作数序与折叠公式随机变异，跨构建不重样；
- **引擎函数原位加密（selfcrypt）**：VM 引擎与授权/验签/完整性/反调试
  关键函数在文件中是密文，运行期窗口解密、用后即焚；
- **多因子反调试**：PEB/断点/内核标志/计时/硬件断点 + 新增父进程
  调试器黑名单、墙钟-tick 漂移检测；
- **完整性守护**：.text/.rdata/.pdata 三段 CRC + 看门狗周期复查
  （±40% 抖动，含授权数据冗余校验）；
- **业务函数自动 VM 化**：源码一行 `// @vmcalc` 标注，构建时自动把
  纯计算函数翻译进 VM（自研 C 子集→VM 汇编翻译器）；
- **运行时密钥多样性**：每次运行 VM 密钥域不同，双次内存转储对比失效；
- **控制流平坦化试点**：关键函数 switch-dispatch 化，静态分支不可直读。

### 2. 授权体系（让它不可伪造）
- **RSA-3072 机器绑定**：序列号/机器码/授权等级/到期时间全部卷入签名，
  改任何一个字符即失效；换机必败；
- **完全离线签发**：私钥只在自己的服务器；客户端运行期零网络、零遥测；
- **签发与台账**：服务器（Ubuntu）+ 图形化签发台（本机 GUI）+ 台账
  哈希链（改/删任何记录都会被检出）+ 重放拦截 + 字段卫生。

## 三、实证（我们拿测试说话）

- **攻防演练 8+ 轮**：覆盖注入/伪造/补丁/组合链/还原/取证/隐蔽/签发链路，
  除公开边界外 **0 破防点**；每轮都有脚本与归档报告；
- **发布门禁 release_check 11/11**：可复现构建、端到端 28 项、攻击面
  12 项、VM 单元/语义/链条全绿；
- **稳定性回归器**：任何改动后 3 连建门槛（防"旧 exe 假象"）；
- **Defender 实测**：静态扫描 0 检出、长驻行为 0 拦截；
- **业务样例**：一个被完整保护的真实小工具（批量哈希校验）——你可以
  下载后亲手"破坏"它（改 license/换机器/换 blob/调时钟）全部被拒。

## 四、诚实边界（不承诺"永不破解"）

- 安装目录可写时可替换公钥重签（所有用户态保护的共同上限）；
- 到期控制依赖本地时钟（可回拨）；完整内存转储可取证明文窗口；
- 单镜像可通过模拟器还原语义（需级联+会话值才有效）；
- 与 main 同页的函数无法参与原位加密（页粒度权限切换的固有限制）。

我们把这些边界**写进公开文档**，每一条都有缓解路径——比起"宣传很猛
的壳"，可信的是证据和边界。

## 五、交付形态

- **离线签发体系**：服务器签发 + 客户端离线验签的完整运营链路（可
  自用于自己产品，也可为第三方提供接入服务）；
- **公开演示**：GitHub 上的受保护示例 + 7 天评估授权（体验完整闭环）；
- **接入向导**：3 步把保护装进自己的 C 程序（生成骨架→写业务→构建）。

## 六、数字一览

- 攻防轮次：8+ 轮 + 3 组矩阵，0 破防（边界外）
- 发布门禁：release_check 11/11 PASS
- 加密函数：5 类关键路径（VM 引擎 + 装载/验签/反调试/完整性）
- 授权强度：RSA-3072 + 机器绑定 + 签名载荷全字段
- 回归纪律：改动即 3 连建门槛 + 矩阵 + Defender 复测
