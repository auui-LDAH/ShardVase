# 关于 ShardVase

**给 Windows 软件一套可以实证的反逆向保护与离线授权：每个功能都有测试依据，
每个边界都公开说明。**

与市面上"宣传很猛的壳"不同，ShardVase 的所有安全主张都可以下载、运行、
亲手破坏来验证——因为我们把过程记录成了攻防档案，把做不到的事写成了
边界清单。

## 它解决什么（一句话）

你的软件被破解、被换机共享、授权管理靠手工 Excel——ShardVase 把这四件事
变成：**VM 混淆执行 + RSA-3072 机器绑定 + 自持签发体系**，默认完全离线、
零遥测。

## 能力速览（每条都有证据）

| 能力 | 说明 |
|------|------|
| VM 混淆执行 | 自定义字节码引擎 + 跨构建变异；引擎函数运行期原位加解密，明文窗口=活动周期 |
| 多因子反调试 | PEB/断点/内核/时序/堆标志；干净环境零误报基线 |
| 完整性守护 | .text/.rdata/.pdata CRC + 看门狗周期复查（含授权数据冗余校验） |
| 机器绑定授权 | RSA-3072；serial/tier/到期/机器码全部卷入签名，改一个字节即失效 |
| 防镜像替换 | VM 镜像包与授权同私钥签名；黑名单（吊销）亦签名 |
| 业务函数自动 VM 化 | 业务源一行标注 `// @vmcalc` → 构建时自动翻译进 VM 执行 |
| 自持签发体系 | 私钥只在你的服务器；防重放；台账哈希链防静默篡改；离线签发 |
| 接入向导 | prot_sdk：三步接入（生成工程 → 写业务 → 构建+授权闭环） |

## 用测试说话

- 攻防演练 **7 轮正式 + 4 组矩阵**；**5 项显式破防全部公开**（附前置条件与缓解路径），每轮有脚本与归档报告
- 发布门禁 **release_check 17/17 PASS**（可复现构建 + 端到端 28 项 + 攻击面 12 项 + 模块契约 + 攻防记录）
- 稳定性回归：任何改动后 3 连建门槛 + UTF-8 判定
- Defender 实测：静态扫描 0 检出，长驻行为 0 拦截
- 公开演示包：下载后亲手"破坏"——比截图有说服力

## 诚实边界（先读再合作）

我们不承诺"永不破解"（任何承诺都不可信）。公开 6 项实证边界，每项都带
缓解路径：

- **安装目录可写** → 可替换公钥重签（所有用户态保护的共同上限，部署要求 ACL 防写）；
- **到期控制依赖本地时钟**（可回拨；商业版需在线时间锚点）；
- **完整内存转储**可取证明文窗口（加密窗口缩小中）；
- **单镜像可通过模拟器还原语义**（需级联 + 会话值才有效）；
- **用户态无法防内核级攻击**（驱动级 dump/hook 不在覆盖）；
- **撤销非实时**（离线黑名单下发有延迟）。

## 接入自己的软件

面向 C/MSVC（Windows x64）开发者：生成骨架工程 → 在
`prot_business_main(ctx)` 写业务 → 一键构建。授权/签发/到期/换机
全部内置，你的客户体验完整闭环。
