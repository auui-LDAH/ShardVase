## 1. 项目是什么

一套**自研、可实证、完全离线可控**的 Windows x64 反逆向保护与授权签发
体系。从代码保护（VM 混淆/函数加密/反调试/完整性）到授权（RSA-3072
机器绑定/离线签发/台账审计），全部代码、密钥与证据掌握在项目方自己手里，
不依赖任何第三方运行时或授权服务。

## 2. 为什么做

软件开发者几乎都会遇到三件事：

- 软件被逆向破解（dump、patch、脱壳）；
- 一份授权被到处拷贝（换机即用）；
- 试用/分级授权靠手工 Excel 管理。

市面上的方案各有短板：VMProtect 类贵且授权弱、在线授权服务把数据放在
第三方手里、"壳"类方案被进程转储就破功。我们的目标是做一套**经得起
实测**的体系：每项能力都有测试依据，每条边界都公开说明。

## 3. 技术主线：代码保护

### 3.1 自定义 VM 混淆引擎

关键逻辑被翻译成**私有字节码**在自研解释器上运行（不是套壳）。构建期：

- 操作数端序（LE/BE）与折叠公式随构建随机变异，跨构建产物互不相同；
- 会话级语义随机化：每次运行取不同等价路径，转储重放无效。

### 3.2 引擎与关键函数原位加密（selfcrypt）

VM 引擎、blob 装载、验签、完整性检查、反调试等关键函数，在文件中是
**密文**，运行时窗口解密、用后即焚。配套：

- **分页隔离**：解密器/CRC/辅助函数放在独立可执行节 `.protxec`，
  避免与加密段同页（页粒度权限切换自伤已根治）；
- **页冲突安全网**：构建期检测加密段与 `main` 同页 → 自动跳过并警告；
- **pdata 边界防御**：加密范围不越段尾（防写坏邻节）。

### 3.3 多因子反调试（12+ 维度）

PEB/断点/内核标志/计时/硬件断点/调试堆/INT3 蜜罐，以及新增：

- **父进程调试器黑名单**（x64dbg/ollydbg/windbg/cdb/ida/gdb）；
- **墙钟与 tick 源交叉漂移检测**。

### 3.4 完整性守护

`.text/.rdata/.pdata` 三段 CRC + 看门狗周期复查（±40% 抖动间隔），
含授权数据三副本冗余校验；RELEASE 构建默认调用级解密窗口（D2b）。

### 3.5 业务函数自动 VM 化（`// @vmcalc`）

源码一行标注，构建时自动把纯计算函数翻译进 VM（自研 C 子集 → VM
汇编翻译器，golden 6/6、流程测试 11/11）。业务逻辑也能进 VM，不再
只保护"授权判定链"。

### 3.6 运行时密钥多样性

每次运行 VM 密钥域不同（差分流内存重编码），双次转储对比失效；
blob 文件与签名不受影响。

### 3.7 控制流平坦化

关键函数 switch-dispatch 化（状态机等价变换），静态分支不可直读。

## 4. 技术主线：授权体系

### 4.1 RSA-3072 机器绑定

授权载荷 = 序列号 + 机器标识（卷序列号/机器 GUID/磁盘物理序列号）+
产品 + 授权等级 + 到期时间，**全部卷入签名**。改任意一个字符即失效；
换机必败（矩阵实测）。

### 4.2 完全离线签发

- 私钥只存在签发服务器（Ubuntu），客户端只持公钥；
- 运行期零网络、零遥测；离线可用是设计基线，不是降级。

### 4.3 签发与台账

- 服务器签发 CLI + 本机图形化签发台（GUI，Taildrop 工作流）；
- 台账：哈希链（改/删任意记录都会被检出）、重放拦截、字段卫生。

## 5. 实证：我们用测试说话

### 攻防演练（7 轮正式 + 4 组矩阵）

覆盖：注入 / 伪造 / 补丁 / 组合链 / 还原（VM 模拟器）/ 取证（进程
转储）/ 隐蔽（看门狗挂起）/ 签发链路（请求-授权文件-台账-时序）/
符号表解析（内存补丁工具链）。

累计 BLOCKED 54 / PARTIAL 58 / **显式破防 5** / SKIP 5。
**5 项破防全部公开**（附前置条件与缓解路径），每轮都有脚本与归档报告。

### 发布门禁（release_check 22/22 PASS）

- 可复现构建（同种子两次构建字节一致）；
- 端到端 28 项（T1-T28）；
- 攻击面 12 项（A1-A12）；
- VM 单元/语义/链条校验（vm_unit/vmc/protchain）；
- 示例工程 7 项（E1-E7）。

### 稳定性回归器

任何改动后 3 连建门槛 + UTF-8 判定（防止"旧 exe 假象"类误判）。

### Defender 实测

静态扫描 0 检出；长驻行为（自解密 + 看门狗周期）0 拦截。

### 可下载的"破坏挑战"

公开演示包（受保护的真实小工具）：改 license / 换机器 / 换 vm.blob /
调时钟——全部被拒。下载后亲手试，比截图有说服力。

## 6. 诚实边界

我们不承诺"永不破解"（任何承诺都不可信）。公开边界包括：

- **安装目录可写**时，可替换公钥重签（所有用户态保护的共同上限，
  部署要求 ACL 防写）；
- **到期控制依赖本地时钟**（可回拨；商业版需在线时间锚点）；
- **完整内存转储**可取证明文窗口（加密窗口缩小中）；
- **单镜像可通过模拟器还原语义**（需级联 + 会话值才有效）；
- **与 main 同页的函数**无法参与原位加密（页粒度权限切换的固有限制）。

每条边界都有缓解路径，全部写进公开文档。

## 9. 复现与构建

# 发布门禁
powershell -ExecutionPolicy Bypass -File tools\release_check.ps1
# 稳定性回归（真机/无 WDAC 环境）

# 攻防矩阵
